Roleta

Os filmes de uma mesma franquia ficam espalhados entre os outros, com uma fatia por filme. Se cair uma delas, o resultado indica por qual filme começar.

Aparência

Escolha um tema pronto ou monte o seu em “Customizado”. Fica salvo neste aparelho.

Conexão com o TMDB

Crie uma conta gratuita em themoviedb.org/settings/api e cole aqui o Token de Leitura da API (ou a chave da API v3). Ela fica salva só no seu navegador.

Dados dos filmes

Busca capa, imagem de fundo, sinopse, ano, gênero e diretor para os filmes que ainda não têm dados. Confira depois se algum foi associado ao filme errado.

Backup

Exporte um backup da sua lista para guardar ou levar para outro aparelho.

Apagar filmes “Quero ver”

Remove da lista só os filmes marcados como “Quero ver”. Os filmes já assistidos, com suas notas e anotações, continuam. Se você estiver conectado, eles também saem da nuvem. Exporte um backup antes se quiser guardar uma cópia.

Última verificação: digite APAGAR para confirmar. Não dá para desfazer.
